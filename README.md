One haiku about debugging, in the 5-7-5 syllable shape, for the
[make.fun bounty](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

> The stack trace points up
> each function blames its mother
> grandma wrote the bug

`main.ts` (Node 22, no dependencies, no network) writes the haiku
deterministically to `/output/entry.txt`. `candidates.md` holds six
drafted candidates with their syllable counts spelled out and scored
against the five published judge criteria.
